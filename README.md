## About Me

I am a Software Engineer operating at the intersection of **Artificial Intelligence** and **Enterprise Backend Engineering**. My work bridges modern AI application development—such as LLM orchestration, intelligent agent architectures, and predictive heuristics—with mission-critical enterprise systems built on **SAP ABAP Cloud**, **SAP S/4HANA**, and modern distributed backends.

My engineering philosophy centers on **lean architecture, zero-dependency craftsmanship, and high-throughput scalability**. Rather than accumulating bloated dependency trees, I build systems engineered from first principles: from authoring **Ishaa** (a zero-dependency ASGI Python framework with custom ORM and WebSocket engine) to designing production **RESTful Application Programming (RAP)** models and Core Data Services (CDS) for enterprise workloads.

- **Enterprise Backend:** SAP Backend Engineer at **Tata Consultancy Services (TCS)**, engineering SAP HANA Cloud integrations, ABAP RAP services, and cloud modernization.
- **Applied AI & Systems:** Author of custom Python ASGI frameworks, predictive heuristic optimization engines, and agentic AI tooling.
- **Academic Foundation:** B.Tech in Artificial Intelligence & Machine Learning from M. Kumarasamy College of Engineering (CGPA: 8.08).
- **Public Technical Leadership:** Invited as Chief Guest and keynote speaker by engineering institutions to lead architectural workshops on Git, GitHub, and collaborative engineering.
